Markov Algorithm Calculator

Markov Algorithms are formal systems used to describe computations and manipulations with symbols. They are based on rules that define how to transform strings of symbols and find applications in various fields, including automata theory and logic.

Rules of Markov Algorithms are written in the form of pairs, where each pair consists of a string to be replaced and the string it will be replaced with. These rules are written sequentially, each on a new line.

A simple replacement is described using ->, while a final replacement is described using =>.

A comment is described at the beginning of a line using //.
